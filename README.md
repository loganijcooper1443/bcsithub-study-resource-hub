## Overview

BCSITHub provides Pokhara University BCSIT learners with a central place to manage academic study and practice. Students can find chapter notes, solved previous questions, syllabus progress, university notices, and other learning resources through a single web portal.

Beyond its resource library, the platform offers a multi-language online compiler, SGPA and CGPA calculators, a Pomodoro timer for focused study, and an AI-powered practice exam quiz generator. Separate student, teacher, and administrator dashboards organize learning content, approvals, and academic management according to each user's role.

## What You Can Do

- Read chapter-based notes and access solved past questions.
- Use offline-first PWA caching for portal content that is available without a continuous connection.
- Work out semester and cumulative results with SGPA and CGPA calculators.
- Structure study time using the integrated Pomodoro focus timer.
- Practice programming by writing and executing code in an online compiler supporting multiple languages.
- Create AI-generated practice exam quizzes for revision.
- Check live university notices and monitor syllabus completion.
- Use role-based student, teacher, and administrator dashboards, including approval panels.

## Using the Portal

1. Launch BCSITHub in a supported modern browser.
2. Choose the dashboard associated with your account role.
3. Explore notes, solved questions, notices, and syllabus details.
4. Enter academic results in the SGPA or CGPA calculator.

When supported content has been cached, the progressive web app can continue providing that content while offline.

## Frequently Asked Questions

### Who is BCSITHub designed for?

The portal is built for Pokhara University BCSIT students, along with the teachers and administrators who support their academic experience.

### What learning resources are available?

BCSITHub includes chapter notes, solved past questions, syllabus tracking, and university notices.

### Are SGPA and CGPA calculations supported?

Yes. Separate tools are available for calculating semester performance through SGPA and cumulative performance through CGPA.

### How can I receive the latest version?

Use the latest build link provided above, or update the local checkout from its configured remote repository. Hosted instances can receive updates through the project's deployment workflow.

### How are application settings managed?

Settings are maintained in the repository's configuration and deployment files. Review the existing project structure and setup documentation before making changes.

### What can I check if the portal fails to open?

First verify that JavaScript is enabled and reload the page. If cached PWA data appears stale, inspect or clear the browser's stored site data. For local installations, review terminal output and confirm that the application was started with the command expected by the repository.

### Why do certain functions need an internet connection?

Offline-first behavior covers supported content and application assets only. Live notices, online compiler functionality, and other connected services may not work without network access.
